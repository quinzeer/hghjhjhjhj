## Sources

Règles de la table (contrôlées par `make verify-phase-0`) :
- `ID` = S1, S2, … ; chaque [Sn] cité plus haut existe ici.
- `Date source` = date de publication ou de mise à jour de la source : `AAAA-MM-JJ`, `AAAA-MM` ou `AAAA` ; `s.d.` si inconnue (non comptée comme source datée).
- `Consulté` = `AAAA-MM-JJ`, jamais dans le futur.
- `Type` ∈ `officiel` (plateforme, régulateur, éditeur ou dépôt du modèle, texte de licence), `publication` (article scientifique, rapport technique), `presse`, `praticien` (créateur, blog, forum), `données` (panel, statistiques tierces).
- `Confiance` ∈ `élevée`, `moyenne`, `faible`.
- Une URL n'est citée que si elle a été ouverte ou vue dans un résultat de recherche pendant la rédaction ; jamais de mémoire.
